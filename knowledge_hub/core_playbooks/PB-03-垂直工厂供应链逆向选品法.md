# 垂直工厂与供应链逆向选品手册 (PB-03)

## 一、核心哲学
以 1688 / 产业带自身的核心生产能力为圆心向外辐射，寻找亚马逊上能吃下自身产能的精准类目。
- **选品公式**：工厂现有模具/产能 + 亚马逊现有 BSR 竞品差评点分析（VOC） + 轻度模具改款 / 组合升级。
- **竞争优势**：出厂价极限、模具壁垒、现货秒发、供应链自控。

## 二、准入硬指标门槛
1. **开模/改模成本**：≤ ¥8,000 元（优先考虑换包装、换配件、加辅料的轻度改良）；
2. **毛利空间**：工厂成本 / 亚马逊售价 ≤ 18%；
3. **竞品差评率**：头部竞品 3.8 ~ 4.2 星（存在大量明确可改良的工艺痛点）。
