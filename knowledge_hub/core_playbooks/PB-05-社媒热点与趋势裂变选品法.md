# 社媒热点与趋势裂变选品手册 (PB-05)

## 一、核心哲学
依托 Sorftime 抓取的 Reddit / TikTok / Temu 热门讨论与短视频传播趋势，在趋势爆发初期抢跑上架。
- **选品公式**：Reddit 讨论热度环比增长 ≥ 50% + TikTok 标签播放量破千万 + 亚马逊现有同款供应不足或评分偏低。
- **打法**：极速打样、极速空派小批量、抓住流量红利窗口期。

## 二、准入硬指标门槛
1. **生命周期判定**：区分“瞬间快闪玩具”与“真实需求爆发”；
2. **知识产权排查**：社媒爆款必须做极高警戒度的 IP、商标与外观专利检索；
3. **供应链响应速度**：从下单到出货 ≤ 5 天。
