# 双市场交叉验证选赛道法 (PB-08)

## 一、核心哲学
红海给分母（需求规模、护城河），蓝海给分子（需求漏点、产品定义缺陷）。两边互证后才下结论。
- **选赛道公式**：红海需求真实 + 劝退线命中 <2 条（或转做周边） + 蓝海需求涨且集中度降 + 供给年轻 + 痛点集中 + 前三痛点有设计解。

## 二、准入硬指标门槛
1. **红海劝退线**（命中 ≥2 条不正面进）：前 5 品牌点击份额 >70%；平均评论 >5,000；90 天新品≈0 或新品点击 <2%；品牌年龄 >5 年；
2. **窗口**：需求在涨（死区 ±2%）且集中度在降（死区 ±0.5pp）；
3. **蓝海四条件**同时成立：需求涨、集中度降、供给年轻（新品占比 ≥20%）、痛点集中（头部痛点 ≥40%）；
4. **产品定义**：前三痛点逐条有设计解，缺一不立项。

## 三、操作步骤
1. 锁口径（窗口、集中度口径、痛点归一化）；
2. 红海六类数 → 数劝退线；
3. 用上位词/场景词找高增长形态词；
4. 下钻 ≥24 个月趋势、差评主题、退货原因；
5. 回成熟市场反向验证蓝海词；
6. 痛点 → 设计解 → 产品定义卡；
7. 三阶段进入：0–90 天拿评论 → 90–180 天 bundle 提客单 → 180 天后复购与壁垒。

## 四、风险与边界
- 单案例经验线，须按类目复核；缺数据判「证据不足」，不估算；
- 差评主题近似退货原因，须标注。
