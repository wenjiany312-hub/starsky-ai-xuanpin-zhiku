# 从0到1破局与冷门蓝海选品手册 (PB-02)

## 一、核心哲学
避开大卖家聚集的主力标品，寻找“大卖家看不上、小卖家吃得饱”的高客单、低竞争垂直类目。
- **选品公式**：月搜索量 5000~20000 + 竞品评价中位数 ≤ 150 + 价格带 ≥ \$35 + CR10 ≤ 45%。
- **破局点**：抓住大卖家 Listing 未做优化的信息差或场景化空白。

## 二、准入硬指标门槛
1. **客单价**：必须 ≥ \$35（留出足够的毛利空间支撑前期测词与开款）；
2. **头部壁垒**：BSR 前 10 名不能有同一品牌占 3 个以上坑位；
3. **退货率**：≤ 5.0%；
4. **生命周期**：非季节性（近 12 个月 Google Trends 与 Sorftime 曲线平稳度波动 ≤ 25%）。
