# 精铺与多变体矩阵选品实操手册 (PB-01)

## 一、核心哲学
精铺的核心不是“盲目乱铺”，而是以低成本多 SKU、多变体在长尾流量池中建立护城河。
- **选品公式**：低起订量（MOQ ≤ 50） + 1688 现货直发 + 标品微改款 + 多颜色/多规格拆分。
- **流量策略**：自然搜索流量为主，自动广告弱打，不盲目砸大词。

## 二、准入硬指标门槛
1. **采购成本**：≤ ¥25 元（单件到手控制在 \$3.5 以内）；
2. **销售定价**：\$14.99 ~ \$24.99（冲动消费价格带）；
3. **退货率红线**：全店平均 ≤ 3.5%；
4. **单款试销包**：首批每个 SKU/变体仅发 20~30 件，以测款为第一要务。
