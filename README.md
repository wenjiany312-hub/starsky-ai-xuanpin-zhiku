# AI 选品智库

输入一个产品想法（中文即可），系统按你选的选品方法论，拉取 SIF / 西柚 / Sorftime / 1688 的实时数据，用规则算出 **做 / 有条件做 / 暂缓 / 不做**，并生成一份可离线打开、可打印的 HTML 选品报告。

- 结论只由规则和阈值算出，AI 只负责解读，改不了结论；每个数字都能追到数据来源和取数时间。
- 方法论可切换、可对比（复用已取数据，不重复花额度），也可以把博主的方法论原文粘进来，自动提炼成判定标准。
- 数据和密钥都只存在本机。

## 需要准备什么

| 项目 | 要求 |
|---|---|
| 电脑 | macOS 或 Windows |
| Python | 3.10 或更新（[python.org](https://www.python.org/downloads/) 下载；Windows 安装时勾选「Add python.exe to PATH」） |
| 数据源 | **至少一个**：SIF 或西柚（搜索量、竞争格局）。**建议**再接 Sorftime（买家讨论、专利、1688 同款） |
| 模型 | 本机 MagPie 网关（默认）；或 DeepSeek / 智谱 / OpenAI 的 API Key |

## 安装与启动

**macOS**

```bash
python3 desktop_launcher.py
```

第一次启动会自动创建运行环境、安装依赖（约 1–3 分钟，只需一次），然后打开浏览器。想要桌面图标：

```bash
python3 desktop_launcher.py --make-app --install
```

**Windows**：双击 `启动AI选品智库.bat`。想要桌面快捷方式，双击 `创建桌面启动快捷方式.bat`。

打开后先看左侧栏的 **「使用说明」**，前三步会显示你卡在哪一步。

**第一次用**：软件自带 7 天 / 3 次试用。想继续用，在左侧「授权」页复制设备码发给发行方换授权码，粘贴激活即可（离线校验，不联网）。
安装细节、授权与 Windows 注意事项见 [docs/安装与使用.md](docs/安装与使用.md)，模型与数据源怎么接见 [docs/配置指引.md](docs/配置指引.md)。

## 更新

```bash
git pull
```

然后重新启动即可。依赖有变化时启动器会自动补装；你的运行记录、密钥和自己导入的方法论都不会被覆盖。

## 自检

装好后可以跑一遍离线自检（不调数据源、不花额度，几秒完成）：

```bash
backend/.venv/bin/python -I backend/test_smoke.py
```

Windows 用 `backend\.venv\Scripts\python.exe -I backend\test_smoke.py`。

## 方法论包

方法论包决定「按什么标准判」：五维权重、阈值、规则开关和 AI 解读视角。最快的方式是在界面里粘贴原文让 AI 提炼；想手写或批量分发，见 [docs/方法论包规范.md](docs/方法论包规范.md)。

## 数据与安全

- 运行记录、报告：`data_storage/`
- 模型与数据源密钥：`config/local/`（文件权限仅本机用户可读）
- 自己导入的方法论：`method_packs/user/`
- 以上目录都不会提交到 Git，也不会被更新覆盖。
- 导入的方法论包只读取文字和参数，里面的脚本不会被执行。
- 数据源报错信息里的 Key 会自动打码，不会出现在日志、报告或导出包里。
