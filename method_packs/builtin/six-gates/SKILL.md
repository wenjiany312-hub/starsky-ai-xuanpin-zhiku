# 六道门风控定档（本平台执行版）

本包不执行包外的任何脚本。所有计算由引擎的 `app/core/six_gates.py` 完成，这里只写口径与顺序。

## 上游三步（六道门之前，必须写进报告）

1. **同特征竞品集**：3–10 个，判据见 lens。填 `peer_count`。
2. **排异常**：硬风险（受限、侵权）→ 不做；运营异常（合并评论、刷评、站外引流、品牌流量、老代新、烧广告）→ 降为观察。填 `anomalies`，多个用「、」分隔。
3. **断崖法找头部**：没做就标「代理指标」。

## 数据源（本平台自动路由）

商品筛选优先走卖家精灵，本包按可用性自动选源，用户在设置里指定的路由永远优先：

| 用途 | 顺序 | 说明 |
|---|---|---|
| 商品/赛道筛选（同特征竞品样本） | 卖家精灵 → Sorftime → 西柚 | 引擎按关键词拉 Top 商品（月销降序），自动算 S、头部月销、断崖、低评论档、参照档 |
| 关键词趋势/需求 | 西柚（免费）→ SIF（付费） | 省点数 |
| 竞争格局 | SIF 固定优先 | 月销/评论档字段只有 SIF top_competitors 带全，西柚格局无销量 |

自动样本 = 关键词下的头部商品，不等于人工同特征集：数字可用，置信度封顶「中」（`peer_auto`）。都未接入时运行会写明「需要接入 卖家精灵 / Sorftime / 西柚 之一」。

## 定档规则

```
fails   = 状态为 fail 的门
unknown = 状态为 unknown 的门

有 fail：
  · 只有发货风险门 fail            → 小批量试款（降到试款量）
  · 其余任何一门 fail              → 不做
无 fail，有 unknown              → 观察（最高只能到观察，不得写「做」）
全过，运营难度=困难               → 做（降目标、少量首批）
全过，其余                        → 做

封顶（在上面结论之后再压一次）：
  · 命中运营异常（anomalies 非空）  → 做 / 小批量试款 降为 观察
  · 同特征竞品 peer_count < 2       → 做 / 小批量试款 降为 观察，置信度「低」
  · 同特征竞品 peer_count < 3       → 置信度最高「中」
```

`fail` 优先于 `unknown`。运营难度**不否决**，只调节目标月销与首批备货。

## 首批

`首批 = 同特征平均月销 S × 趋势系数 k × 2 个月`。填 `peer_avg_monthly` 才是方法口径；缺 S 时回落到目标月销，结果会标注「可能偏高」。困难档 ×0.5（待核对）。高成本不设系数（无依据，由人定）。

## 六道门与判据

| 门 | 判据 | 缺什么会导致 unknown |
|---|---|---|
| 1 合规门 | IP 已检索无命中、类目资质齐、非受限品 | IP 检索没跑、证书未核 |
| 2 体量门 | 站内头部月销 ÷ 目标月销 ≥ 3 | 没有头部月销样本 |
| 3 盈利门 | ROI ≥ 120% 且单件净利 > $5；或单件净利 > $10 | 缺采购价/头程/FBA/佣金 |
| 4 趋势门 | 目标月 ÷ 当前月 ≥ 0.7（下滑超 30% 不做） | 缺趋势数据 |
| 5 产品原因门 | 未饱和 = 低评论档均月销 ÷ 100–200 评论参照中位 ≥ 0.15 | 参照档样本不足 |
| 6 发货风险门 | 首批资金在可承受上限内 | 资金上限未填 |

## 公式（与引擎一致）

```
landed    = (cost_cny + head_cny) / rate
net_price = price × (1 − discount)
referral  = net_price × commission
payout    = net_price − referral − fba
profit    = payout − landed
margin    = profit / net_price
roi       = profit / landed
price_min = (landed + fba) / ((1 − commission) × (1 − discount))
cost_max_cny = (net_price × (1 − commission) − fba − target_profit) × rate − head_cny
price_120 = (landed × 2.2 + fba) / (1 − commission)
acos_break_even = profit / net_price
难度%     = 低评论档平均月销 ÷ 自然前 5 平均月销 × 100
首批      = 同特征平均月销 S × k × 2（缺 S 回落目标月销）；困难 ×0.5；试款 50–100
补货      = 目标月销 × 1 个月
```

## 参数怎么填（本平台）

| 事实 | 参数名 | 说明 |
|---|---|---|
| 售价 | `sale_price_usd` | 折前价；有 discount 再填折扣 |
| 采购价 | `cost_cny` | 没给就走 `supply_price_cny_median`（1688） |
| 头程 | `head_cny` | 没给就走 `freight_usd × 汇率` |
| FBA | `fba_fee_usd` | 当期后台费率 |
| 佣金 | `referral_pct` | 默认 15%，欧洲/日本按 32% 复核 |
| 折扣 | `discount` | 0–1 |
| 目标月销 | `target_orders` | 默认 200（美国站下限） |
| 头部月销 | — | 取竞争样本最大月销，**代理指标，需人工复核** |
| 趋势 | `trend_target` / `trend_current` | 不给就用搜索量同比折算 |
| 资金上限 | `max_loss_ok` | 未填 → 发货风险门 unknown |
| IP 检索 | `ip_reviewed` | 未填 → 合规门 unknown |
| 同特征竞品数 | `peer_count` | 未填 → 置信度不封顶；填 <2 → 只能观察 |
| 同特征平均月销 S | `peer_avg_monthly` | 未填 → 首批回落目标月销并标注偏高 |
| 运营异常 | `anomalies` | 列表或「、」分隔字符串；非空 → 降为观察 |

## 硬护栏

1. **不编数据**：缺什么写「待补」，并指出它让哪道门失效；不猜采购价、CPC、转化率。
2. **两个 15% 不要混**：难度 >15% = 简单；未饱和 ≥0.15 = 未饱和。
3. **两个 3 倍不要混**：头部/目标 ≥3；断崖后相邻 1.3–1.5 倍。
4. **代理指标标注**：用样本最大值代替断崖法找头部时，必须写「代理指标，需人工复核」。
5. **阈值是 C 级经验**：平台佣金、FBA、VAT、时限以当期后台为准，不以本表为准。
6. **五维分数只作参照**：不得用评分推翻六道门结论。
