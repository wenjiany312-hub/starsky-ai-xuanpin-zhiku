# 配置指引

> 装好之后、开跑之前要做的两件事：**接模型**、**接数据源**。
> 两件都是买家自己提供（[安装与使用.md](安装与使用.md) 第一节说了为什么）。软件只负责连、测、用，不代买、不转卖。

## 一、先看这张清单

| 你要什么 | 模型 | 数据源 |
|---|---|---|
| 能打开、能看界面、能看记录 | 不需要 | 不需要 |
| 能跑出结论（关键词 → 竞争 → 需求） | 至少一个可用模型 | **SIF 或西柚**任一家 |
| 报告完整（含用户声音、专利初筛、真实 FBA 费） | 同上 | **SIF + Sorftime** |
| 能算真实毛利（1688 报价） | 同上 | Sorftime，或本机 1688 抓取 |
| 方法论编译（用模型生成自己的方法包） | 一个**支持工具调用**的强模型 | 无硬要求 |

软件左下「工作台」的体检会按这张表逐项打勾；缺什么会写「缺口」，不会编数。

## 二、接模型

### 路线 A：本机 MagPie（推荐，免 Key）

MagPie 是一个跑在本机的模型网关，你把各家模型的 Key 填进 MagPie，软件只连 MagPie 一个口。

1. 安装并启动 MagPie，确认它在本机 `3425` 端口监听（默认地址 `http://127.0.0.1:3425/v1`）；
2. 在 MagPie 里填入你已有的模型渠道（你的 Claude / DeepSeek / 智谱 / OpenAI / 中转 Key 等），
   并在 MagPie 里记住模型名（例如 `group/never-stuck`、`claude/claude-opus-5-5`）；
3. 打开软件 → 左侧「模型设置」：
   - 「MagPie 本地网关」卡片应显示 **已配置 · 无需密钥**；
   - 点「测试」→ 出现「连通正常 · 模型名 · XXX ms」；
   - 点「刷新」后，卡片下方会列出 MagPie 当前可用的模型；
4. 在上方「角色分工」里分配模型（点「更换模型」）：

   | 角色 | 干什么 | 怎么选 |
   |---|---|---|
   | 综合研判与报告 | 判定理由、报告正文、对比解读 | 能力最强的那个 |
   | 意图识别与翻译 | 关键词翻译、标题摘要 | 便宜、快即可 |
   | Skill 方法论执行（带工具） | 按方法一步步跑、调 MCP 工具 | **必须支持工具调用**，别选纯聊天小模型 |

5. 点右上「测试主力模型」复核一遍。

MagPie 没启动时，「测试」会报连接失败；先把 MagPie 打开再测。软件不会替你启动 MagPie。

### 路线 B：直连服务商

不想装 MagPie 也行。在「模型设置」里找到对应卡片 →「配置」→ 填 Base URL 与 API Key →「测试」→ 分配角色：

| 提供方 | 说明 |
|---|---|
| DeepSeek | 官方接口，填 Key 即可 |
| 智谱 GLM | 官方接口 |
| OpenAI | 官方接口，也可填兼容中转的 Base URL |
| Anthropic | 官方接口 |
| OpenRouter | 聚合，一个 Key 多模型 |
| Ollama | 本机跑，地址默认 `http://127.0.0.1:11434/v1`，无需 Key |

所有模型配置保存在本机 `config/local/settings.json`（权限 0600），不上传、不随安装包分发。

### 模型只影响「说话」，不影响「判定」

五维打分、硬闸门、降档由本地规则引擎计算；换模型不会改变同一个输入的结论，只改变理由写得好不好。
模型连不上时，报告会明确标注「AI 正文未生成」，规则结论照常输出——不会拿模型失败冒充「没有风险」。

## 三、接数据源

### 三个原则

1. **按能力接，不按品牌接**：引擎要的是「关键词趋势」「竞争格局」「用户声音」「1688 报价」这些能力，谁提供都行；
2. **同一能力多家时自动回落**：SIF 挂了会试西柚；
3. **没接的能力就是缺口**：报告里会写「此项数据缺失」，可信度下调，绝不补一个看起来像真的数字。

### 各数据源能补什么

| 数据源 | 补的能力 | 必需性 |
|---|---|---|
| **SIF** | 关键词趋势、竞争格局、需求生命周期、真实 FBA 费、成本上限、ASIN 画像、流量与词 | 与西柚**二选一**；要完整报告就接 |
| **西柚（xydc）** | 关键词指标与趋势、竞争 ASIN、市场机会、商品筛选、爆发品发现 | SIF 的备源 |
| **Sorftime** | 类目报告与 Top100、商品搜索/详情、关键词详情、Reddit 用户声音、专利初筛、1688 云端搜索 | 建议接；缺了用户声音与专利只能记缺口 |
| **1688 本地抓取** | 1688 搜厂、商品详情、图片/视频下载 | 可选；没接 Sorftime 时用它算毛利 |
| **卖家精灵** | 关键词指标、ASIN 反查词 | 可选，付费；当前只用到这两项，单独接不足以跑完整流程 |

H10 目前没有接入。要加，走下面「自定义 MCP」的通用办法，前提是它提供 MCP 服务。

### 接入步骤

1. 打开左侧「数据源」；
2. 点右上「**接入 MCP**」，填：
   - **ID**：固定用 `sif` / `sorftime` / `xydc` / `1688_scraper` / `sellersprite`，引擎靠 ID 和能力表认人；
   - **名称**：随便写，只影响显示；
   - **类型**：远程选「HTTP / SSE」，本机程序选「本地 stdio」；
   - 远程填 **URL** 与 **Headers**（一般是 `Authorization: Bearer <你的 Key>`，以服务商文档为准）；
   - 本机 stdio 填启动命令、参数、环境变量；
3. 保存后点该连接器的「**重测**」，状态变「在线」才算通；
4. 首次接 1688 本地抓取会弹出登录窗口，登录一次即可（会话存在本机）。

### 已经配过的，不用重填

软件会自动读取：

- Claude 的 `~/.claude.json` 里的 MCP 服务；
- ZCode 的 `~/.zcode/cli/config.json`；
- 本软件自己保存的自定义连接器。

所以在 Claude 里已经能用的 SIF / Sorftime，打开「数据源」点「**全部重测**」通常就直接在线了。
名字里带 `sif` / `sorftime` / `xydc`（或「西柚」）/ `1688` / `sellersprite`（或「卖家精灵」）会被自动认领；
认领错了，就在「接入 MCP」里用固定 ID 显式加一条。

### 各家的 Key 从哪来

| 数据源 | 去哪拿 |
|---|---|
| SIF | SIF 后台（sif.com）的 MCP / API 页，复制地址与密钥 |
| 西柚 | 西柚开放平台生成 MCP Token（mcp.xydc.com） |
| Sorftime | Sorftime 后台开通 MCP 后复制地址与密钥（mcp.sorftime.com） |
| 卖家精灵 | 开通卖家精灵 MCP 权限后获取（付费） |
| 1688 本地抓取 | 不需要 Key，装好本机程序、首次登录 1688 账号 |

每家界面会变，以他们自己的文档为准；本软件只需要「地址 + 认证头」这两样。

### 数据源安全边界

- Key 只存在本机 `config/local/settings.json`，不进报告、不进日志、不上传；
- 安装包里不含任何 Key；如果你在别人机器上看到预填的 Key，说明包打错了，别用；
- 数据源额度归各服务商，软件只做调用与展示，不转售、不缓存对外提供。

## 四、开跑前体检

「工作台」顶部会做一次体检：

| 结果 | 含义 | 处理 |
|---|---|---|
| 全绿 | 模型通、关键词能力有源、市场与供应链可选源也在 | 直接跑 |
| 黄色警告 | 能跑，但报告会有缺口（如没接 Sorftime） | 想更完整就补；不补也能跑，报告会写明缺什么 |
| 红色阻断 | 没模型，或没有任何关键词数据源 | 按提示去「模型设置」/「数据源」 |

体检结果可手动重测，不会缓存很久；改了配置回来刷新即可。

## 五、方法论与知识库

| 目录 | 谁的 | 说明 |
|---|---|---|
| `method_packs/builtin/` | 你随版本发布 | 内置方法包，升级时会被新版本覆盖 |
| `method_packs/user/` | 买家自己 | 导入或编译的方法包，**升级不会动**，也不进 git |
| `knowledge_hub/` | 你随版本发布 | 知识库条目与判定卡 |

- 「方法论库」页可以查看每个方法的步骤、判定阈值和适用条件；
- 用模型编译自己的方法包需要有效授权（到期只读时不可用）；
- 方法包内容是**数据**，软件只读不执行，导入前仍建议看一眼来源。

## 六、第一次跑通的自检

按顺序做完，任何一步不通就先停下修：

- [ ] 「模型设置」里主力模型「测试」通过，三个角色都分配了；
- [ ] 「数据源」里至少 SIF 或西柚显示「在线」；
- [ ] 「工作台」体检无红色；
- [ ] 「新建选品」输入一个你熟悉的关键词，跑到出报告；
- [ ] 报告里每个关键结论都能点开看证据（数据来自哪个源、哪一天）；
- [ ] 报告里「数据缺口」一栏写的缺失项符合你的实际配置；
- [ ] 授权页显示「试用中 · 剩 X 天 / Y 次」或「已授权」。

## 七、常见问题

| 现象 | 处理 |
|---|---|
| 模型卡片显示「需要配置」但 MagPie 明明开着 | 确认 MagPie 在 `3425`，点「测试」；仍失败就在「配置」里把 Base URL 改成实际端口 |
| 模型测试通过，但跑起来报「工具调用失败」 | 「Skill 方法论执行」角色选了一个不支持 tools 的模型，换掉 |
| 数据源显示「在线」但报告说缺数据 | 该能力没有对应连接器（比如只接了西柚，需求生命周期只有 SIF 有），看体检的能力清单 |
| 卖家精灵接了仍提示缺词 | 目前只用到 `keyword_info` 与 `asin_keywords` 两项能力，完整词库仍需 SIF / 西柚 |
| 1688 连接器离线 | 确认本机抓取程序路径与启动命令正确；首次需要登录；也可先接 Sorftime 顶上 |
| 换了电脑，数据源全没了 | 本软件里填的配置在程序目录下的 `config/local/`，整个目录拷过去会一起带走；但从 `~/.claude.json` / ZCode 自动读到的数据源在用户目录，新机器上要重接一次（或把 `config/local/` 单独拷过去） |
