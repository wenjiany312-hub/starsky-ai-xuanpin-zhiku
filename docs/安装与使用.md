# 安装与使用（买家版）

> 怎么在自己电脑上装起来、拿到试用、换成正式授权、升级与排错。
> 模型和数据源怎么接，见 [配置指引.md](配置指引.md)；想导入自己的方法论，见 [方法论包规范.md](方法论包规范.md)。

## 一、先知道你买的是什么

软件本体 + 内置方法论与知识库（及其后续更新）。**不含**数据源 Key、模型 Key：
模型用你自己的（本机 MagPie，或 DeepSeek / 智谱 / OpenAI 兼容 / Ollama 的 Key），
数据源用你自己的（SIF、西柚、Sorftime、1688、卖家精灵等）。

第一次打开看到的是「开跑前体检」，缺什么按提示去接。什么都没接也能打开、能看说明，
但跑不出像样的结论——这是设计如此，不是安装失败。

## 二、macOS 安装

1. 下载 `AI选品智库-vX.Y.Z-mac.zip`，解压到 `~/Applications/AI选品智库`
   （**不要放在 iCloud 同步目录**，也不要直接在 zip 里双击）；
2. 打开「终端」，进入目录并启动：

   ```bash
   cd ~/Applications/AI选品智库
   python3 desktop_launcher.py
   ```

3. 首次启动会自动建 `backend/.venv`、装依赖（约 1–3 分钟），然后打开浏览器 `http://127.0.0.1:8006`；
4. 想要一个双击就能开的图标（可选）：

   ```bash
   python3 desktop_launcher.py --make-app --install
   ```

   之后从**桌面**上的「AI选品智库」打开即可，不用再开终端（想放进「应用程序」，把它拖进去就行）。

被系统拦住时：

- 右键点 `AI选品智库` →「打开」，或到「系统设置 → 隐私与安全性」点「仍要打开」；
- 提示「Python 未安装」或版本过低：装 [python.org](https://www.python.org/downloads/) 的 3.10+（Apple Silicon 选 universal2）；
- 启动失败时不要反复双击：在终端里跑 `python3 desktop_launcher.py`，错误会打印在窗口里，也可以看 `data_storage/logs/server.log`。

关闭与重启：关掉浏览器标签**不会**停服务，下次打开会复用已在跑的后端；彻底停止用
`python3 desktop_launcher.py --stop`（`--status` 看状态）；8006 端口被占用时先 `--stop` 再启动。

## 三、Windows 安装

1. 安装 **Python 3.10 或更新**：[python.org](https://www.python.org/downloads/) 下载，
   安装第一屏勾选 **「Add python.exe to PATH」**，然后 Install Now；
2. 下载 `AI选品智库-vX.Y.Z-windows.zip`，解压到简单路径，例如 `D:\AI选品智库`
   （避免 `C:\Program Files` 和深层中文目录）；
3. 双击 `启动AI选品智库.bat`。首次会建虚拟环境、装依赖，约 1–3 分钟，完成后自动打开浏览器；
4. 想要桌面图标：双击 `创建桌面启动快捷方式.bat`；
5. 启动窗口一闪而过、或浏览器没打开：双击 `一键启动终端.bat`，在终端窗口里看完整报错；
6. 彻底停止：双击 `停止AI选品智库.bat`。

注意：首次运行 SmartScreen 可能提示「Windows 已保护你的电脑」→「更多信息」→「仍要运行」；
杀毒软件可能拦 `backend\.venv\Scripts\python.exe` 的联网，把安装目录加入白名单；
不要把整个目录放在 OneDrive 同步盘里跑。

## 四、试用与授权

1. 新装第一次打开起算：**7 天或 3 次运行，先到为准**。试用信息存在本机用户目录（`~/.aixp-license/`），
   移动软件文件夹、覆盖安装都不会重置；系统日期被往回调超过一天，试用立即停止；
2. 左侧菜单最下面一行是授权状态：`试用中 · 剩 X 天 / Y 次`、`已授权 · 剩 X 天`、`授权已到期 · 只读`；
3. 要正式使用：打开「授权」页，点「复制设备码」，把 `XXXX-XXXX-XXXX` 发给卖家；
4. 收到 `XZ1.` 开头的一整段授权码后，在同一页粘贴 →「激活」，立刻生效，无需重启；
5. 续费：卖家给同一设备码签一个更晚的到期日，粘贴覆盖即可。换电脑或重装系统后设备码会变，需要用新设备码重新换码。

到期后软件**只读**，不会删除或加密任何旧数据：

| 仍然可用 | 需要有效授权 |
|---|---|
| 打开软件、看工作台 | 发起新的选品运行 |
| 选品记录、运行详情、逐步进度 | 重新运行已有选品 |
| 报告、报告 HTML、证据 / 事实 / 结论文件下载 | AI 选品助手对话 |
| 导出星空 S1 产物目录 | 用模型编译自己的方法论 |
| 数据源、模型、方法论、知识库管理 |  |

## 五、升级

下载新版 zip，**先停止服务**（macOS `--stop`，Windows 双击 `停止AI选品智库.bat`），解压覆盖程序目录，
**保留** `data_storage/`（运行记录与报告）、`config/local/`（你的模型与数据源配置）、`method_packs/user/`（你导入的方法论）。
授权码绑定设备码、不绑定版本，正常覆盖升级不需要重新激活。每版改了什么见 [更新日志.md](更新日志.md)。

## 六、故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 结论显示「未研判」，报告缺数据 | 一个数据源都没接 | 看「开跑前体检」，至少接 SIF 或西柚 |
| 模型连不上 | MagPie 没启动 / Key 失效 | 先启动 MagPie，或到「模型设置」换一个能测通的模型 |
| 能跑但采购价是估算 | 没接 Sorftime，也没启用 1688 抓取 | 接 Sorftime，或在 1688 抓取里登录 |
| 授权页显示「试用已结束 · 只读」 | 7 天 / 3 次用完 | 复制设备码发给卖家换码 |
| 粘贴授权码提示「校验不通过」 | 抄漏字符、换了行、或码不是这台机器的 | 整段重新复制，不要手打；确认设备码一致 |
| Windows 双击没反应 | Python 未进 PATH / 杀软拦截 | 用 `一键启动终端.bat` 看报错，重装 Python 勾选 PATH |
| macOS 提示「无法验证开发者」 | Gatekeeper | 右键 → 打开 |
