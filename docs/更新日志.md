# 更新日志

> 每次发版写清楚：新增了哪些判定标准、哪些知识卡、哪些修复。升级方法见 [安装与使用.md](安装与使用.md)。

## v3.0.0

**判定与方法论**

- 新增内置方法论「六道门风控定档」：合规 → 体量 → 盈利 → 趋势 → 产品原因 → 发货风险定档，
  结论四档 做 / 小批量试款 / 观察 / 不做；运营难度只调节目标与备货、不否决；阈值为经验口径（C 级），非平台规则。
- 六道门按方法口径对齐：首批改用「同特征平均月销 S × k × 2」（缺 S 才回落目标月销并标注偏高）；
  新增「运营异常」「同特征竞品数」两个输入，命中运营异常或同特征不足 2 个时「做 / 小批量试款」降为「观察」；
  置信度按同特征竞品数封顶。删除无依据的「采购价 ≥ ¥70 首批 ×0.7」。
- 六道门新增「同特征竞品筛查」步骤：按关键词自动拉头部商品样本（卖家精灵优先，Sorftime / 西柚回落），
  从月销 + 评论数两列自动算出 S、头部月销、断崖（≥1.3 倍）、低评论档均值、参照档中位、难度与未饱和，
  直接喂进六道门；自动样本不等于人工同特征集，置信度封顶「中」，报告里口径全摊开。
- 数据源可路由、可指定：商品/市场筛选默认 卖家精灵 → Sorftime → 西柚；关键词趋势/信息 西柚（免费）优先 →
  SIF（付费）回落；竞争格局固定 SIF 优先（月销字段只有它带全）。启动时自动扫描已接入的 MCP 并按序回落，
  全部没接时明确提示「需要接入谁」；新增 `PUT /api/v1/mcp/connectors/routes` 供用户手动指定顺序（优先级最高），
  方法包也可在 data_sources 里声明偏好。
- 同一次运行的数据可换不同方法论重算结论，不额外消耗数据额度。
- 没有数据时判「未研判」，不再给出看似成立的「暂缓」；估算出来的毛利不触发一票否决。
- 软性未过项（没触发硬闸门的未过规则）不管几条，结论只降一档：这些规则已经在五维分数里扣过分，
  原来每条再降一档、且有未过项就不给「做」，同一个问题被罚了两到三次（74.9 分的品会落到「不做」）。
  硬闸门（如采购价高于成本上限、毛利低于生存线）照旧直接「不做」。

**图片找货**

- 新建选品可丢一张产品图（或贴公网图片地址）：认出产品 → 给出中英关键词 → 搜市场与 1688 货源；
  有公网地址时额外做 1688 以图搜同款与外观专利以图检索。识别出的词只补空位，不覆盖手填内容。
